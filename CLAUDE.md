# Bitandpix Trends — инструкция для Claude

## Контекст

Ты помогаешь вести Telegram-канал трендов студии bit&pix. Канал публикует видеотренды для создателей контента — чтобы использовать их в сценариях.

Настя присылает тебе видео → ты анализируешь → пишешь готовый текст поста.

---

## Шаг 1 — Перед работой: проверь ID

Открой файл `trends/index.md` в этом репозитории. Найди последний использованный ID.

- Формат ID: `BPT` + трёхзначный номер. Например: `BPT001`, `BPT042`.
- Возьми следующий по порядку (если последний `BPT007` — следующий `BPT008`).
- Если таблица пустая — начни с `BPT001`.

**Никогда не повторяй ID, которые уже есть в таблице.**

---

## Шаг 2 — Анализ видео

Когда Настя присылает видео — **всегда** анализируй через fal.ai. Только так можно услышать музыку, речь и звуки — они часть тренда.

**Модель:** `openrouter/router/video`  
**Ключ:** `~/.claude/.env.fal`, переменная `FAL_KEY`

```js
import { fal } from "@fal-ai/client";
import fs from "fs";

fal.config({ credentials: process.env.FAL_KEY });

const buf = fs.readFileSync("/path/to/video.mp4");
const videoUrl = await fal.storage.upload(new Blob([buf], { type: "video/mp4" }));

const result = await fal.run("fal-ai/any-llm", {
  input: {
    model: "openrouter/router/video",
    prompt: "Analyze this video: describe the visual format, editing technique, camera work, music/audio, speech or text on screen. Focus on the repeatable pattern — what trend or format does this represent that other creators could replicate?",
    video_url: videoUrl,
  },
});

console.log(result.data.output);
```

Твоя задача — найти **тренд**: воспроизводимый паттерн, приём, формат. Не пересказывай весь сюжет видео.

**Тренд — это:**
- Конкретный монтажный или визуальный приём
- Характерное движение + звук + действие (в чёткой последовательности)
- Тип перехода, текста на экране, реакции, скорости
- То, что другой автор может воспроизвести в своём контенте

**Не тренд:** уникальный сюжет этого конкретного видео.

## Уточняющие вопросы (задавай если нужно)

Спрашивай Настю если:
- Тренд в видео неочевиден — попроси указать конкретный момент (тайм-код)
- Видео слишком длинное и трендов несколько — уточни, на какой фокусироваться
- Плохое качество — попроси другой пример или объясни словами
- Название из index.md уже встречалось — уточни, это новый тренд или тот же?

## Шаг 3 — Структура поста

Пиши СТРОГО по этому шаблону. Никаких отступлений от структуры.

---

```
[Название тренда]

[2–4 предложения: что за приём, как выглядит, что делает автор/камера/монтаж.
Описывай паттерн — то, что можно повторить. Не пересказывай сюжет этого видео.]

Раскадровка:
• [момент/действие 1]
• [момент/действие 2]
• [момент/действие 3]
[добавляй пункты если нужно]

Как использовать:
1. [Пример 1 — конкретная ниша или формат]
2. [Пример 2 — другая ниша]
3. [Пример 3 — ещё одна ситуация]

ID: BPT___

[сервис для создания сценариев](https://app.bitandpix.ru) | [услуги: smm, дизайн, продакшн](https://bitandpix.ru)
```

---

**Правила для раздела "Как использовать":**
- Три примера — всегда из разных ниш или форматов
- Конкретные ("ресторан снимает процесс сборки блюда"), не абстрактные ("любой бизнес")
- Не привязаны к конкретному видео Насти — это общие применения тренда

**Правила для описания тренда:**
- Пиши от настоящего времени ("камера замедляется", "автор резко разворачивается")
- Длина описания: 2–4 предложения, не больше
- Раскадровка: 3–6 пунктов

---

## Шаг 4 — Сразу после написания поста (не ждать ничего)

Как только текст поста готов — немедленно:

1. Добавь строку в `trends/index.md`:

```
| BPT___ | [Название тренда] | ГГГГ-ММ-ДД |
```

2. Закоммить и запушь:

```bash
cd ~/bitandpix-trends
git add trends/index.md
git commit -m "add BPT___: [Название тренда]"
git push
```

3. Выдай Насте текст поста.

**Порядок важен:** сначала пуш, потом текст Насте. Реестр должен быть в GitHub до того, как сессия завершится.

---

## Чего не делать

- Не описывай сюжет видео вместо тренда
- Не меняй структуру поста
- Не придумывай ID без проверки index.md
- Не делай примеры абстрактными
- Не добавляй пункты, которых нет в шаблоне
- Не жди подтверждения от Насти перед пушем — пушить сразу автоматически
