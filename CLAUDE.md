# Bitandpix Trends — инструкция для Claude

## Контекст

Помогаешь вести Telegram-канал трендов студии bit&pix. Канал публикует видеотренды для создателей контента — чтобы использовать их в сценариях.

Настя присылает видео → ты анализируешь → пишешь готовый текст поста → пушишь реестр → отдаёшь текст Насте.

---

## Шаг 1 — Проверь следующий ID

Открой `trends/index.md`. Найди последний ID в таблице.

- Формат: `BPT` + трёхзначный номер (`BPT001`, `BPT042`).
- Возьми следующий по порядку.
- Таблица пустая — начинай с `BPT001`.

**Никогда не повторяй ID из таблицы.**

---

## Шаг 2 — Анализ видео

Когда Настя присылает видео — **всегда** делай оба шага ниже. Не пропускай ни один.

**Ключ fal.ai:** `~/.claude/.env.fal`, переменная `FAL_KEY`.

---

### 2а — Визуальный анализ (кадры)

Замени `/path/to/video.mp4` на реальный путь к файлу:

```bash
ffmpeg -i "/path/to/video.mp4" -vf "fps=1" /tmp/bpt_frame_%03d.jpg -y
```

Прочитай каждый кадр через Read. Смотри:
- Что на экране: люди, предметы, фон, атмосфера
- Субтитры и текст — читай дословно
- Монтаж: как меняются планы, есть ли переходы, какие
- Камера: крупный/общий план, движение, статика

---

### 2б — Транскрипция аудио через fal.ai

Сохрани и запусти этот скрипт (замени путь к видео):

```js
import { fal } from "@fal-ai/client";
import fs from "fs";
import { execSync } from "child_process";

const FAL_KEY = fs.readFileSync("/Users/maxkaymaks/.claude/.env.fal", "utf8")
  .match(/FAL_KEY=(.+)/)[1].trim();
fal.config({ credentials: FAL_KEY });

execSync(`ffmpeg -i "/path/to/video.mp4" -vn -q:a 0 /tmp/bpt_audio.mp3 -y 2>/dev/null`);

const audioUrl = await fal.storage.upload(
  new Blob([fs.readFileSync("/tmp/bpt_audio.mp3")], { type: "audio/mp3" })
);

const result = await fal.subscribe("fal-ai/elevenlabs/speech-to-text", {
  input: { audio_url: audioUrl, language_code: "ru" },
  logs: true,
  onQueueUpdate: (u) => u.logs?.forEach(l => console.log("[stt]", l.message)),
});

console.log(result.data.text);
```

Запуск (нужен Node.js; `@fal-ai/client` установить один раз через `npm install @fal-ai/client`):

```bash
node analyze.mjs
```

**Интерпретация результата:**
- Только `[музыка]` — речи нет, весь текст на экране визуальный (субтитры).
- Есть слова — это речь автора, включи в анализ тренда дословно.

---

### Что искать в анализе

**Тренд — это воспроизводимый паттерн:**
- Конкретный монтажный или визуальный приём
- Последовательность: движение + звук + текст + действие
- Тип перехода, реакции, скорости, субтитра
- То, что другой автор может снять в своей нише

**Не тренд:** уникальный сюжет этого конкретного видео.

---

### Уточняющие вопросы (только если нужно)

Спроси Настю, если:
- Тренд неочевиден — попроси указать тайм-код нужного момента
- В видео несколько трендов — уточни, на каком фокусироваться
- Плохое качество — попроси другой пример или словесное описание
- Название из `index.md` уже встречалось — уточни, новый тренд или тот же?

## Шаг 3 — Напиши пост

Пиши **строго по шаблону**. Никаких отступлений от структуры.

```
[Название тренда]

[2–4 предложения: что за приём, как выглядит, что делает автор/камера/монтаж.
Описывай паттерн — то, что можно повторить. Не пересказывай сюжет видео.]

Раскадровка:
• [момент/действие 1]
• [момент/действие 2]
• [момент/действие 3]
[добавляй пункты если нужно, максимум 6]

Как использовать:
1. [Пример 1 — конкретная ниша]
2. [Пример 2 — другая ниша]
3. [Пример 3 — ещё одна ситуация]

ID: BPT___

[сервис для создания сценариев](https://app.bitandpix.ru) | [услуги: smm, дизайн, продакшн](https://bitandpix.ru)
```

**Правила описания:**
- Настоящее время: "камера замедляется", "автор резко разворачивается"
- 2–4 предложения, не больше
- Раскадровка: 3–6 пунктов

**Правила раздела "Как использовать":**
- Ровно три примера, всегда из разных ниш
- Конкретные: "ресторан снимает сборку блюда", не "любой бизнес"
- Не привязаны к видео Насти — это общие применения тренда

---

## Шаг 4 — Пуш и отдача текста

Сразу после написания поста — **не ждать ничего**:

1. Добавь строку в `trends/index.md`:

```
| BPT___ | [Название тренда] | ГГГГ-ММ-ДД |
```

2. Закоммить и запушь:

```bash
cd ~/bitandpix-trends
git add trends/index.md
git commit -m "add BPT___: [Название тренда]"
git push
```

3. Выдай Насте готовый текст поста.

**Порядок важен:** сначала пуш, потом текст. Реестр должен быть в GitHub до конца сессии.

---

## Чего не делать

- Не пропускай анализ через fal.ai — кадры без аудио неполный анализ
- Не описывай сюжет видео вместо тренда
- Не меняй структуру поста
- Не придумывай ID без проверки `index.md`
- Не делай примеры абстрактными
- Не жди подтверждения от Насти перед пушем — пушить сразу автоматически
- Не добавляй разделы, которых нет в шаблоне
