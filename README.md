# Bitandpix Trends

Telegram channel publishing video trends for content creators. Each trend comes with a breakdown and usage examples for scenario writing.

## Channel

[@bitandpix_trends](https://t.me/bitandpix_trends)

## Post format

Each trend = 2 posts:
1. Video + full trend description, storyboard, 3 usage examples, links
2. Source video only (no text)

- [app.bitandpix.ru](https://app.bitandpix.ru) — scenario creation tool
- [bitandpix.ru](https://bitandpix.ru) — smm, design, production studio
